САЙТ-ПОРТАЛ СГЗ — ПАКЕТ ДЛЯ ПУБЛИКАЦИИ

Состав:
- index.html — адаптивный интерактивный сайт

Бесплатная публикация:
1. Создайте аккаунт GitHub (если его ещё нет).
2. Создайте публичный репозиторий с названием sgz-yamburg.
3. Загрузите index.html в корень репозитория.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch, ветку main, папку /(root), нажмите Save.
6. Через несколько минут сайт будет доступен по адресу вида:
   https://ВАШ-ЛОГИН.github.io/sgz-yamburg/

После публикации пришлите точный адрес сайта — QR-код будет добавлен в презентацию и проверен.
Важно: публичный сайт сейчас является демонстрационным. Не публикуйте на нём внутренние документы, персональные данные, контакты, сведения ограниченного доступа и детальные планы реагирования.
